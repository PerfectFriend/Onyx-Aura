**Правила ведения журнала (обязательны для всех):**

1. **Записи никогда не удаляются и не редактируются задним числом.**  
   Можно только добавлять новые записи в конец файла.
2. Каждая запись начинается с чёткого заголовка, содержащего:
   - Таймстамп в формате `YYYY-MM-DD HH:MM TZ`
   - Тег типа записи: `[MESSAGE]`, `[REPORT]`, `[AUDIT]`, `[ASSIGNMENT]`, `[DECISION]`, `[NOTE]`
   - Адресацию: `От: Имя → Кому: Имя`
3. Внутри записи допускается Markdown.
4. Этот журнал — единственный канал официальной переписки между Гришей и Женей по эволюции проекта.
5. Женя после выполнения этапа пишет сюда `[REPORT]`.
6. Гриша отвечает `[AUDIT]` + `[ASSIGNMENT]` (или `[DECISION]`).
7. Все решения, меняющие План Эволюции или Манифест, фиксируются здесь тегом `[DECISION]`.
